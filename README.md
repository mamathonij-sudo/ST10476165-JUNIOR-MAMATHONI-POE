#dzuvhaelectricalsolution
## Project Description 
DZUVHA Electrical Solution is an website that is developed to provide information about electrical services that are offerd to customers around South Africa and mostly the rural communities.The website provides information about electrical installation, solar panel solutions, electric fence, housing wiring including other electrical services. 

Website Pages
- Home Page
- About Us Page
- Services Page
- GALLERY Page
- CONTACT Page

Technologies Used: 
- HTML5
- CSS3
- JavaScript(still not used yet)
- Visual Studio Code
